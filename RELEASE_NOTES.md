# WebTester Pro v1.0.0 Release Notes

**DEVELOPED BY JOJIN JOHN**  
**Release:** `v1.0.0`

WebTester Pro v1.0.0 is the first public GitHub release of the cross-browser web security testing extension for Firefox, Chrome, Edge, and Brave.

## Release Assets

| File | Description |
|---|---|
| `WebTesterPro-Firefox.zip` | Firefox extension folder packaged as ZIP |
| `WebTesterPro.xpi` | Firefox XPI package |
| `WebTesterPro-Chrome.zip` | Chrome, Edge, and Brave extension folder packaged as ZIP |
| `WebTesterPro-Source.zip` | Source archive |

## Highlights

- Payload browser for common web security testing categories.
- Encoder and decoder tools for URL, Base64, HTML, Unicode, and Hex.
- JWT toolkit for decoding and reviewing token claims.
- Regex library for finding common secrets and indicators.
- Optional AI assistant support for OpenRouter, Groq, Ollama, and LM Studio.
- Notes, checklists, wordlists, recon references, and report helpers.
- Firefox sidebar support.
- Chrome/Edge/Brave Manifest V3 build.

## Install

Firefox users can download `WebTesterPro-Firefox.zip`, extract it, and load `manifest.json` from `about:debugging`. Chrome, Edge, and Brave users can download `WebTesterPro-Chrome.zip`, extract it, enable Developer mode in the browser extension page, and use **Load unpacked**.

## Safety Notice

Use this extension only on systems you own or have explicit written permission to test.
