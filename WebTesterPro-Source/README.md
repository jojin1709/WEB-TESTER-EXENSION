# WebTester Pro

**DEVELOPED BY JOJIN JOHN**

WebTester Pro is a browser extension for authorized web application security testing. It supports Firefox, Chrome, Edge, and Brave with payloads, encoding tools, JWT review, regex helpers, notes, checklists, wordlists, recon references, reports, and optional AI provider support.

> Use only on systems you own or have explicit written permission to test.

## Install

### Firefox

1. Install from Mozilla Add-ons: https://addons.mozilla.org/en-US/firefox/addon/webtester-pro/
2. Or download `WebTesterPro-Firefox.zip` or `WebTesterPro.xpi` from the GitHub release.
3. For temporary testing, open `about:debugging`, choose **This Firefox**, click **Load Temporary Add-on...**, and select `manifest.json`.
4. For XPI install, open `about:addons`, use **Install Add-on From File...**, and select `WebTesterPro.xpi`.

### Chrome, Edge, And Brave

1. Download `WebTesterPro-Chrome.zip` from the GitHub release.
2. Extract it.
3. Open `chrome://extensions`, `edge://extensions`, or `brave://extensions`.
4. Enable **Developer mode**.
5. Click **Load unpacked** and select the extracted folder.

## Build

```bash
bash scripts/build.sh all
```

Release files are generated in `release/`.
