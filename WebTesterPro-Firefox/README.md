# WebTester Pro

**DEVELOPED BY JOJIN JOHN**

This folder contains the Firefox build of WebTester Pro.

## Install Temporarily

1. Extract `WebTesterPro-Firefox.zip`.
2. Open `about:debugging`.
3. Select **This Firefox**.
4. Click **Load Temporary Add-on...**.
5. Select `manifest.json` from this folder.

## Install XPI

Open `about:addons`, use **Install Add-on From File...**, and select `WebTesterPro.xpi`.
